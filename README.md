# 🚀 Vedamo

> **One Search. Every Possibility.**

Vedamo is an AI-powered Android application that simplifies app discovery through natural language search. Instead of manually searching across multiple apps, users simply describe what they need. Vedamo understands the query using **Google Gemini API**, recommends the most relevant applications, and opens the selected app with the searched content.

## ✨ Features

- 🤖 AI-powered natural language search
- 🧠 Intent recognition using Google Gemini API
- 📱 Smart app recommendations
- 🚀 Opens the selected app with the searched query
- 🔐 Firebase Authentication
- 🎨 Modern UI with Jetpack Compose

## 🛠 Tech Stack

- 💻 Kotlin
- 📱 Android Studio
- 🎨 Jetpack Compose
- 🤖 Google Gemini API
- 🔐 Firebase Authentication
- 🌐 OkHttp
- 🖼️ Coil
